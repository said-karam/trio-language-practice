# Trio, language practice

> Proof of concept, not a commercial product. This repository is a write-up only; the source code is private.

## Problem

I wanted to practise Italian and Spanish between lessons, with exercises built from my own course material, for free.

## What I built

- One app with a course per language (Italian and Spanish, A1 to A2)
- Practice in rounds: anything I miss comes back until a round is clean
- Flashcards with spaced repetition, and progress tracking (streak, daily goal, accuracy, weak spots)
- New lessons built with Claude: the app prepares the source pages and a precise prompt, Claude writes the lesson, and the app checks and repairs the result before saving
- Works offline once loaded, and progress syncs across devices

## Key decisions

- **No paid AI API.** Lessons are generated by copy and paste with a free Claude account, so the app costs nothing to run.
- **Never trust generated content blindly.** Everything pasted back from the AI is repaired, type-checked and shown as plain text, never run. Tests confirm every accepted answer in every lesson is marked correct.
- **One codebase, many languages.** Everything that depends on the language lives in one folder per course, so adding a language is mostly adding content.

## Stack

JavaScript (no build step), installable web app (PWA), pdf.js, Cloudflare Pages Functions and R2.

## Status

In personal use. Not offered commercially.

Built with AI-assisted development (Claude Code).
